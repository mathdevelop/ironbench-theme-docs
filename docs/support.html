Support policy

Response time

We reply to every request within 2 business days, Monday to Friday, excluding public holidays. Critical bugs that break a store are fixed as a priority.

What's covered

  • Questions about Anvil's features, sections, and settings
  • Help setting up the theme as shown in this documentation
  • Bugs in the theme's code, which we fix in a theme update

What isn't covered

  • Custom code, or problems caused by edits to the theme's code
  • Installing, configuring, or fixing third-party apps
  • Design work, store setup, or content entry

For custom work, we recommend hiring a Shopify Partner. Always duplicate your theme before you edit its code.

Help us help you

To get an answer faster, include:

  • Your store URL, and a preview link if the theme isn't published
  • The page where the problem happens and the steps to see it
  • A screenshot, plus the browser and device you used
