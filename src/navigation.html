Header and navigation

Anvil's header puts search in the middle, with the account and cart on the right and the main menu below.

Main menu and mega menu

The header uses the menu selected in Header > Main menu (by default, main-menu). Edit it in Content > Menus.

  • A top-level item with no child links is a plain link.
  • A top-level item with child links opens a dropdown.
  • When those child links have their own child links, the dropdown becomes a mega menu: each second-level link is a column heading and its children are listed below it.

Example structure for a hardware store:

Fasteners
  Screws        → Wood screws, Machine screws, Drywall screws
  Bolts and nuts → Hex bolts, Carriage bolts, Nuts, Washers
  Anchors       → Wall plugs, Sleeve anchors
Hand tools
  Hammers, Pliers, Wrenches, Measuring
Power tools

On small screens, the menu opens in a side drawer with the same structure.

Menu promotion

Add a Menu promotion block to the header to show an image, heading, and link inside a mega menu. In Main menu item, type the exact name of the top-level menu item, for example Fasteners.

Customer accounts

The account icon opens Shopify's customer account menu, so customers can sign in without leaving the page. Choose which links appear in Header > Customer account menu. The icon only appears when customer accounts are turned on in Settings > Customer accounts.

Top bar

The Top bar section sits above the header. Add Message blocks for short notices, such as "Order by 2 PM for same-day dispatch", and pick a Secondary menu for links like Trade accounts or Store locations. The secondary menu shows on large screens only.

Footer

The footer has four kinds of blocks:

  • Brand information: your logo, a short text, and social media icons. Add social links in Theme settings > Social media.
  • Menu: a heading and a menu, such as footer.
  • Text: a heading and text, for example opening hours or a trade counter address.
  • Email signup: a newsletter form.

The bottom bar can show a country or region selector, a language selector, Follow on Shop, payment icons, and policy links. The selectors only appear when you have more than one country or language set up in your markets.
